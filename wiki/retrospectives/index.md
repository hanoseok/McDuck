# Retrospectives

Use this directory for structured reflection after releases, major tasks, incidents, or long debugging sessions.

* [Retrospective Template](/templates/retrospective-template.md) - Copy this for each release/task retrospective.

# Suggested Retro Cadence

* One retrospective for each stable release.
* One retrospective for a snapshot line if it involved repeated debugging.
* One retrospective after major architecture changes or user-facing workflow changes.
