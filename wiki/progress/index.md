# Progress

Use this directory for status snapshots and development progress notes.

* [2026-06-21 OKF Wiki Foundation](2026-06-21-okf-wiki-foundation.md) - Initial wiki structure and repository baseline.

# How to Add Progress

1. Create a dated file named `YYYY-MM-DD-short-topic.md`.
2. Use `type: Progress Report` in frontmatter.
3. Link to the project/module/decision that the progress affects.
4. Add a short entry to `wiki/log.md` or this directory's `log.md` when one exists.
